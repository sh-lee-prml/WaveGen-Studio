# WaveGen Studio 사용법

[English](USER_GUIDE.md) · [설치](INSTALL_KO.md) · [README](../README_KO.md)

## 생성과 재생

왼쪽에서 목소리를 고르고 영어 문장을 입력한 뒤 **음성 만들기** 또는 Ctrl+Enter를 누릅니다. Flash는 4단계, V-Spec은 별도 체크포인트를 사용하는 50단계 모델입니다. 한 번 불러온 모델은 앱을 종료할 때까지 유지합니다.

최신 결과는 넓은 화면에서 작성 영역 오른쪽, 작은 화면에서 생성 버튼 바로 아래에 표시됩니다. **생성 음성 보기**로 직접 이동할 수 있습니다. 생성 완료가 자동 재생이나 화면 이동을 일으키지는 않습니다. WAV 다운로드·Speech Edit·결과 상세를 사용할 수 있습니다. 결과는 24kHz 모노입니다.

초안과 설정은 브라우저에 보관하며 화면 언어는 별도로 저장합니다. 사이트 데이터를 지우면 이 설정은 사라지지만 앱의 `data/` 녹음은 남습니다.

## 길이·속도·시드

예상 길이는 처리 시간이 아니라 완성될 음성 길이입니다. 펼치면 구간별 문장을 볼 수 있습니다. 긴 글 자동 분할은 기본으로 켜져 있으며 문장·단어 경계로 나누어 하나의 WAV로 합칩니다. 한 요청은 UTF-8 기준 5,000바이트까지이며 구간마다 억양이 달라질 수 있습니다.

**세부 설정**에서 시드와 매번 새 시드 옵션을 고를 수 있습니다. 실제 사용한 시드를 기록합니다. 기록의 **문장·설정 불러오기**는 바로 생성하지 않고 초안을 복원하며, 덮어쓴 초안은 되돌릴 수 있습니다.

목표 길이는 새 음성 전체에 대해 0.2–600초를 지정하며 속도 대신 적용됩니다. 완성된 오디오를 늘이는 기능은 아닙니다. 지나치게 짧은 목표는 거절될 수 있고 긴 목표는 부자연스러운 쉼을 만들 수 있으므로 예상 길이 근처에서 시작하세요.

## 참조 음성

**내 목소리 추가** 또는 기존 목소리 설정을 엽니다. 한 사람의 또렷한 영어 문장 3–10초를 권장합니다. 직접 녹음했거나 사용 허락을 받은 자료를 쓰세요.

1. WAV/MP3를 선택하거나 끌어 놓습니다. 최대 50MB·120초이며 브라우저에서 24kHz 모노 WAV로 변환합니다.
2. 참조 편집에서 파형을 드래그하거나 시작·끝 시간을 입력합니다. 저장할 참조는 **30초 미만**이어야 합니다.
3. 선택 원본과 처리본을 들어봅니다. 앞뒤 무음 제거는 말 사이의 쉼을 유지합니다. 선택적 피크 조정은 −3dBFS를 목표로 최대 +12dB까지 증폭하며, 소음과 이후 생성 음량에도 영향을 줄 수 있습니다.
4. 남긴 구간에서 실제 말한 대사를 Reference Text에 그대로 적고 요청 시 일치 확인을 합니다. 앱이 단어를 자동으로 판독하지는 않습니다.
5. 이름과 선택 사항인 이미지를 설정해 저장합니다. 기존 설정을 열기만 해서는 오디오가 바뀌지 않습니다.

편집 중 되돌리기·다시 실행·원본 복원을 사용할 수 있습니다. 보존하는 원본은 변환된 24kHz 모노 WAV이며 MP3 원본 바이트는 아닙니다. 잘못 선택한 파일이 열리지 않으면 현재 녹음을 유지하며 교체만 취소할 수 있습니다. 향상 미리듣기는 적용하거나 현재 버전 유지를 선택한 뒤 저장합니다. 미저장 변경이 있으면 닫기·페이지 이동 전에 확인합니다.

이미지는 최대 10MB의 PNG/JPEG/WebP를 받아 중앙을 잘라 512×512 PNG로 만듭니다. 이미지가 목소리를 바꾸지는 않습니다. 삭제한 목소리는 휴지통에서 복원할 수 있고 이미 만든 결과는 그대로 남습니다.

## 음성 향상

두 기능 모두 로컬 NVIDIA RE-USE를 사용하며 기본 꺼짐입니다. Prompt Enhancement는 준비한 참조 오디오를 처리하고, 전후 비교 후 명시적으로 적용해 저장합니다. Reference Text를 고치는 기능은 아닙니다. Speech Enhancement는 생성 결과를 처리하고 원본과 별도 결과로 보관합니다. 향상에 실패해도 완료된 TTS 원본은 기록에 남습니다.

향상은 음색·숨소리도 바꿀 수 있으며 깨끗한 녹음을 항상 개선하지는 않습니다. 참조 구간이나 처리 옵션을 바꾸면 이전 향상 미리듣기는 무효가 됩니다.

## Speech Edit

결과의 음성 편집을 열고 파형·키보드·시간 입력으로 구간을 고릅니다. 선택 부분을 듣고 남기기·삭제·재생성을 사용합니다. 재생성은 영어 대사와 목소리·모델을 지정합니다. 선택 길이를 유지하면 뒤 음성 위치를 유지하고, 자동 길이는 위치를 바꿀 수 있습니다.

저장은 새 기록을 만들며 원본을 유지합니다. 열린 편집 창에서 되돌릴 수 있습니다. 경계에는 짧은 페이드를 적용하지만 주변 억양과 매끄럽게 연결된다고 보장하지 않습니다. 편집 후 전체 문장은 원본 표시로 남으며 실제 편집 음성과 다를 수 있습니다.

## 기록·중지·복구

문장이나 목소리 이름으로 기록을 검색하고 과거 페이지를 불러옵니다. 원본과 향상본은 묶어서 표시합니다. 문장·설정을 불러올 때 이전 목소리가 없다면 사용 가능한 목소리를 다시 선택해야 합니다.

**중지**는 지원하는 계산 경계에서 반영합니다. 최초 모델 준비가 끝날 때까지 기다릴 수 있으며 저장이 시작되면 완성 결과를 반환할 수 있습니다. 중단한 TTS의 미완성 오디오는 저장하지 않습니다. 연결 중단·새로고침 후에는 작업을 다시 확인하며, 필요하면 상태 확인·재시도 버튼을 사용하세요. 브라우저 저장소 제한이 있으면 새로고침을 넘는 복구가 제한될 수 있습니다.

## 저장·백업

프로필·원본/처리본·이미지·WAV·설정·휴지통·편집 이력은 설치 폴더의 `data/`에 있습니다. 합성을 위해 외부 음성 서비스로 업로드하지 않습니다. 최초 설치와 명시적인 업데이트는 배포 파일을 다운로드합니다.

**앱 종료** 후 `data/` 전체를 백업하세요. 설치 위치를 옮길 때는 DLL과 모델을 포함한 전체 앱 폴더를 보관합니다. 휴지통과 이력은 자동 삭제하지 않아 공간이 늘어납니다. [업데이트·백업 안내](UPDATING_KO.md)를 참고하세요.
