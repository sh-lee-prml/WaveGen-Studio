# 목소리 기여하기

[English](VOICE_CONTRIBUTIONS.md) · [목소리 제안 양식](https://github.com/sh-lee-prml/WaveGen-Studio/issues/new?template=voice_submission.yml)

다른 사용자가 라이브러리에서 고를 수 있는 또렷한 영어 참조 녹음을 환영합니다. 오디오와 정확한 Reference Text를 보내주시면 품질·출처·조건·허락을 검토한 뒤 이후 배포에 반영할 수 있습니다. 제출 즉시 자동 등록되지는 않습니다.

## 함께 보내주세요

- **오디오:** 한 사람이 완전한 문장을 말하는 깨끗한 3–10초 WAV를 권장하며 30초 미만으로 준비하세요. 음악·다른 화자·단어 중간 잘림을 피하고 길이를 맞추려고 무음을 추가하지 마세요.
- **Reference Text:** 파일에서 말하는 영어 대사를 정확히 적어주세요. 내용 요약이 아니라 실제 대사여야 합니다.
- **표시 이름:** 짧은 이름이나 가상 별칭을 제안할 수 있습니다. 다른 사람의 신원이나 추천·보증을 암시하지 마세요. 이미지도 별도 사용 권한과 출처가 필요합니다.
- **출처·변경:** 녹음한 사람과 원본 URL, 리샘플링·잘라내기·음량 조정·향상 등 이미 적용한 변경을 알려주세요.
- **라이선스·표시 조건:** 정확한 라이선스 또는 허락 내용, 출처 URL, 필요한 저작자 표시, 재배포·가공 허용 여부를 적어주세요. 무료 다운로드가 곧 재배포 허락은 아닙니다.
- **녹음자 허락:** 본인의 목소리인지 알려주세요. 다른 화자라면 이 녹음을 TTS 참조로 공개 공유하고 합성 음성을 만드는 용도에 대한 허락 근거를 설명해주세요. 녹음 파일 라이선스와 화자 허락은 별개일 수 있습니다.

GitHub 이슈와 첨부 파일은 공개됩니다. 개인 녹음·연락처·신분증·서명 문서 등 비공개 자료는 올리지 마세요. 허락 내용을 요약하고, 추가 확인이 필요하면 유지보수자가 적절한 방법을 안내할 수 있습니다. 사용·공유 권한이 없는 유명인 영상, 다른 사용자의 목소리 등은 제출하지 마세요.

## 검토 후 반영

파일과 대사 일치, 참조 품질, 출처·조건·표시·허락을 확인합니다. 더 나은 녹음이나 정보를 요청하거나 범위·품질·권한이 불명확하면 반영하지 않을 수 있습니다. 목소리만 듣고 동의를 추정하지 않습니다.

반영 시 제출한 라이선스와 출처를 유지하고 24kHz 모노 변환 등 준비 과정도 기록합니다. 참조 프로필 등록이며 새 모델 학습이나 실제 인물의 완벽한 재현·보증을 약속하는 것은 아닙니다. 오류나 수정 사항은 이슈로 알려주세요.

제출한 녹음에 Studio의 MIT 라이선스가 자동 적용되지는 않습니다. 녹음의 조건이 더 자유롭더라도 WaveGen 모델의 **CC BY-NC 4.0 비상업 조건**은 유지됩니다. [라이선스 안내](LICENSING.md)를 확인하세요.
