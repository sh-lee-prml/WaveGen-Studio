# 업데이트와 백업

업데이트는 사용자가 직접 실행합니다. 작업 중 앱·모델·런타임을 몰래 교체하지 않습니다.

1. **앱 종료**를 누릅니다. 브라우저 탭만 닫으면 앱이 계속 실행됩니다.
2. 설치 폴더의 `data/` 전체를 별도 백업합니다. 프로필·오디오·원본·이미지·휴지통·편집 이력이 있습니다. 초안과 화면 언어는 별도 브라우저 저장소입니다.
3. 새 배포 안내를 읽고 `scripts/`가 있는 폴더에서 다음을 실행합니다.

   ```powershell
   & .\scripts\update.ps1 -InstallDirectory 'C:\Apps\WaveGen Studio'
   ```

   실제 설치 경로로 바꾸세요. 생략하면 앱에 동봉된 스크립트는 앱 위치를 추정하고 소스 폴더의 스크립트는 `%LOCALAPPDATA%\WaveGen Studio`를 사용합니다.
4. 다운로드·체크섬·백업·교체가 끝나면 EXE를 다시 실행합니다.

업데이트는 앱이 닫혀 있어야 하며 `data/`와 관리 대상이 아닌 파일을 유지합니다. 교체하는 파일은 `backups/`에 보관합니다. 별도의 `data/` 백업도 유지하세요.

특정 버전은 `-ReleaseTag 'v0.2.0-beta.1'`, 모델 선택은 `-Models flash,vspec,reuse`로 지정합니다. 태그 기본값은 베타를 포함한 최신 공개 배포입니다. 0.2 업데이트는 기존 설치의 모델 선택을 유지합니다. 0.1에서 일부 모델만 설치한 경우 새 앱 ZIP을 별도 폴더에 풀고 위 명령으로 기존 설치 경로를 지정하세요. 나머지 매개변수는 [영어 안내](UPDATING.md#select-the-version-and-models)를 참고하세요.

`.studio-install.json`이 없는 과거 설치는 이 스크립트로 덮어쓰지 않습니다. 공개 버전을 새 폴더에 설치하고 이전 설치와 백업을 유지하세요. 두 앱을 종료하고 데이터 호환성을 확인한 뒤 `data/`의 복사본을 이전할 수 있습니다.

앱·런타임은 GitHub Releases에서, 네이티브 모델 팩은 원래 [LeeSangHoon/WaveGen Hugging Face 저장소](https://huggingface.co/LeeSangHoon/WaveGen)에서 받습니다. 매니페스트가 모델 리비전과 `config.json` 해시를 고정하며, 모델 다운로드가 필요할 때 검증한 설정에서 실제 팩 경로를 읽습니다. 앱만 업데이트하는 경우 바뀌지 않은 검증된 모델을 다시 받지 않고 재사용하며, 유효한 다운로드 캐시도 재사용합니다.

실패하면 `data/`나 백업을 지우지 말고 오류를 확인한 뒤 같은 배포로 재시도하세요. 수동 복원은 앱 종료 후 호환되는 앱·런타임·모델 묶음을 함께 복원해야 합니다. 미래 버전의 데이터 형식 변경은 별도 마이그레이션 안내가 필요할 수 있어 무조건적인 다운그레이드를 보장하지 않습니다. 출처가 다른 DLL이나 모델 파일을 하나씩 섞지 마세요.

문제를 제보할 때 버전·오류를 보내되 개인 경로나 녹음은 제외하세요. [버그 제보](https://github.com/sh-lee-prml/WaveGen-Studio/issues/new?template=bug_report.yml) · [개발 안내](BUILDING.md)
